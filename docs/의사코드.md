# 조각김치 이물검출 라벨링 도구 — 기능별 의사 코드

팀원이 코드를 처음 볼 때 읽는 문서입니다. **1장**에서 파일 위치를 보고, **2장**에서 전체 흐름을 잡은 뒤, **3장**에서 필요한 기능의 의사 코드를 찾아 실제 파일로 들어가면 됩니다. 각 파일 맨 위 주석에도 같은 내용이 요약돼 있습니다.

**설계 원칙 네 가지**

1. **기능별 폴더.** BBox는 `bbox/`, 파일 형식은 `yolo/`, 검수는 `review/`처럼 기능 하나가 폴더 하나에 모여 있습니다.
2. **화면과 로직 분리.** `yolo/`, `review/workspace.py`, `review/status_store.py`, `validation/validator.py`, `bbox/bbox_model.py`는 tkinter를 쓰지 않습니다. 저장 규칙이나 검사 로직은 화면 없이 테스트할 수 있습니다.
3. **BBox 좌표는 항상 원본 이미지 픽셀 기준.** 화면 좌표 변환은 `src/ui/canvas.py`의 `to_canvas()` / `to_image()`에서만 합니다.
4. **원본 이미지 폴더는 절대 수정하지 않음.** 모든 결과는 `작업자/`, `검수자/`에만 저장됩니다.

**메인 창(LabelingApp) 조립 방식**

메인 창 기능이 많아서 `LabelingApp` 클래스를 기능별 Mixin으로 나눠 여러 파일에 두고, `src/ui/main_window.py`에서 합칩니다. 각 Mixin의 `self`는 모두 같은 LabelingApp 객체이므로, 다른 파일의 함수도 `self.save()`처럼 그대로 호출할 수 있습니다.

```python
class LabelingApp(LayoutMixin, ShortcutMixin, LoadSaveMixin, NavigationMixin,
                  BoxEditMixin, ClassMixin, ReviewMixin, FilterMixin,
                  PanelMixin, ValidationMixin, SessionMixin):
```

### 3.1 실행 — `main.py`

```

### 3.2 로그인 / 로그아웃 — `src/auth/login.py`, `src/auth/logout.py`

```

    창을 로그인 크기(500×360)로 설정
    LoginFrame 표시 (이전 이름·역할 미리 채움)
    로그인 버튼 / Enter:
        이름이 비었으면 경고
        로그인 화면 제거
        LabelingApp(root, 이름, 역할, on_logout=show_login) 생성

    미저장 변경 있음 → maybe_save()  (저장 / 버리기 / 취소)
    없음            → "로그아웃할까요?" 확인

**역할별 차이**

| | 작업자 | 검수자 |
|---|---|---|
| 선택 가능한 상태 | EDITED (자동) | PASS, EDITED, REVIEW, REVIEWED |
| 저장 위치 | `작업자/` (이미지 복사본 + TXT) | `검수자/<상태>/` (TXT만) |
| 라벨 불러오는 순서 | 작업자/ → 원본 | 검수자/ → 작업자/ → 원본 |

### 3.5 BBox 편집 — `src/ui/canvas.py` (마우스), `src/bbox/bbox_manager.py` (데이터)

```
마우스 누름:
    HUD 위                 → 무시 (더블클릭 = 수정 패널)
    선택 박스 모서리 핸들   → 크기 조절 시작 (가로·세로)
    선택 박스 테두리        → 크기 조절 시작 (그 방향만, 테두리 가운데 작은 핸들 표시)
    선택 박스 안쪽          → 이동 시작        (그리기 모드에서도 가능)
    선택·이동 모드          → 클릭한 박스 선택 (겹치면 작은 박스 우선)
    그리기 모드:
        미확정 박스 있음 → "Enter로 확정하거나 Esc로 취소" 안내, 그리기 막음
        없음           → 새 박스 그리기 시작

마우스 드래그:
    그리기   → 점선 미리보기 + 크기(px) 표시
    이동     → 이미지 밖으로 못 나가게 이동
    크기 조절 → 반대편으로 넘어가면 핸들 방향도 뒤집기
    (이동·크기 조절은 처음 3px 움직일 때 Undo 저장 → 단순 클릭은 수정으로 안 침)

마우스 놓음:
    그리기: 4px 미만 움직임 → '클릭 = 박스 선택'
            너무 작은 박스   → 추가 안 함
            그 외           → add_box()
    이동·크기 조절 끝 → box_changed()  (너무 작아졌으면 Undo로 취소)

add_box(박스):           Undo 저장 → 현재 Class → 상태 '신규' + '미확정' → 선택
confirm_pending():  Enter    미확정 해제 → 선택 해제
cancel_pending():   Esc      미확정 박스 삭제
nudge_selected():   방향키   1px 이동 (Shift = 10px)
delete_selected():  Delete   선택 박스 삭제
undo_action():      Ctrl+Z   스냅샷 복원

_after_boxes_changed():      # 모든 변경 뒤 공통
    미저장 표시, boxes_changed = True
    상태가 비었거나 PASS / REVIEWED 면 → EDITED
    캔버스, 라벨 표, HUD, CSV 정보 갱신
```

### 3.8 검수 규칙 — `src/review/review_rules.py`

**6.2 2단계 전수 검수**와 **6.3 100% Cross Review** 절차를 저장 규칙으로 옮긴 부분입니다.

```
_check_review_rules():        # 검수자가 저장할 때만
    PASS:
        이번에 박스를 고쳤다         → 불가 "EDITED로 저장하고 이유 기록"
        Class 4 가 있다             → 불가 "수정(EDITED) 또는 REVIEW"
    EDITED:
        고친 게 없다 (처음 EDITED)   → 불가 "정상이면 PASS / REVIEWED"
        고쳤는데 Note가 비었거나 그대로 → 불가 "수정 이유 기록"
    REVIEW:
        Note가 비었다               → 불가 "애매한 점 기록 (추측하지 않음)"
    REVIEWED:
        Cross Review 대상이 아니다   → 불가
        이번에 박스를 고쳤다         → 불가 "EDITED(재수정)로 저장 → 다시 Review"
        Class 4 가 남아 있다        → 불가
        직전 처리자가 나 자신이다    → 불가 "다른 검수자가 교차검수"

Cross Review 대상 판정 (src/review/workspace.py cross_review_reasons):
    검수 기록이 없다 (2단계 전) 또는 REVIEWED  → 대상 아님
    검수 기록이 EDITED                       → "수정·신규 라벨"
    검수 기록이 REVIEW                       → "REVIEW였던 이미지"
    TXT에 Class 4                            → "Class 4 발견"
    TXT에 박스가 하나도 없음                  → "Empty Label"
```

```
검수 흐름 요약
    2단계:  정상 → PASS  /  오류 → 수정 + 이유 → EDITED  /  애매 → 이유 → REVIEW
    3단계:  (EDITED · REVIEW · Class 4 · Empty Label)
            정상 → REVIEWED (다른 검수자)  /  오류 → 수정 → EDITED → 다시 3단계
```

### 3.10 이동 · 미저장 경고 — `src/ui/navigation.py`, `src/ui/file_actions.py`

```
go_next() / go_prev():
    필터가 켜져 있으면 필터 목록 기준
    처음 / 마지막이면 안내만
goto(idx):
    같은 이미지면 무시
    maybe_save() 통과 → load_index(idx)

maybe_save():   (이동, 폴더 열기, 창 닫기, 로그아웃 전에 호출)
    변경 없음 또는 미저장 경고 OFF → 진행
    아니면 [예: 저장 후 진행] [아니오: 버리고 진행] [취소: 머무름]
```

### 3.11 필터 — `src/review/review_filters.py`

```
set_filter(REVIEW | EDITED | CROSS):
    같은 버튼 다시 누르면 해제
    해당 이미지가 없으면 안내
    view_indices = 조건에 맞는 이미지 인덱스 목록
    현재 이미지가 목록에 없으면 첫 이미지로 이동

조건:
    REVIEW / EDITED → 표시용 상태(검수자 기록 우선, 없으면 작업자 기록)가 같음
    CROSS           → Cross Review 대상
```

### 3.12 Validation — `src/validation/validator.py`, `src/validation/validation_dialog.py`

```
run_validation():
    폴더 안 열었으면 안내, 미저장이면 저장 여부 확인
    validate_folder(현재 역할 기준으로 불러올 라벨) → 결과 창

검사 항목:
    오류  형식(값 5개·정수 Class·숫자), 없는 Class, Class 4, 좌표 0~1 밖, 너비·높이 ≤ 0,
          CSV에 박스가 있는데 TXT 없음
    경고  이미지 경계 넘음, 너무 작은 박스, 중복 박스,
          CSV 박스 수 ≠ TXT 박스 수, Scene Type 모순, 짝 이미지 없는 TXT

결과 창:  오류 N / 경고 N 요약 + 표, 더블클릭 → 해당 이미지로 이동
```

※ Validation은 **파일 형식·규칙** 검사입니다. 박스가 이물을 정확히 감쌌는지는 사람이 검수합니다.

### 3.13 화면 갱신 — `src/ui/panels.py`, `src/ui/thumbnails.py`

```
refresh_all():
    파일 이름, 진행률 (현재 / 전체), 필터 버튼 강조
    refresh_table()       라벨 목록 표: No / Class / 위치(x,y,w,h) / 상태(미확정·선택됨·신규·수정)
    refresh_completed()   라벨 완료 이미지: 내 역할 CSV 기록 순서, 완료율 바
    refresh_csv_info()    저장될 status / assignee / reviewer / scene_type 미리보기
    HUD, 썸네일

썸네일:
    화면에 들어가는 개수만 생성, 현재 이미지가 보이도록 자동 스크롤
    상태 배지(PASS/EDITED/REVIEW/REVIEWED), 라벨 박스 표시
    캐시 최대 300개, 저장하면 해당 썸네일 다시 생성
```

### 3.14 단축키 — `src/ui/shortcuts.py`

| 키 | 기능 |
|---|---|
| Ctrl+O / Ctrl+S / Ctrl+Enter | 폴더 열기 / 저장 / 저장 후 다음 |
